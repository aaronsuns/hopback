How to search Claude Code history and find an old session

You fixed that bug two weeks ago in a Claude Code conversation. Which one was it? This page shows how to find and reopen old sessions, and how Hopback makes it a keystroke.

Why finding old Claude Code sessions is hard

Claude Code keeps your conversations, but the title of a session is often just the first thing you typed, and across many projects there are hundreds of them. Claude Code itself can resume earlier conversations (for instance with claude --resume or /resume in a session), which is useful when you remember roughly when and where. It is less useful when you remember only what was said.

Search by title, folder and text with Hopback

Press ⌃⇧⌘C to open Hopback's search in History mode. It covers every Claude Code conversation on the Mac.

  • Type to filter by title and folder.
  • With three or more characters Hopback also searches the conversation text. Those matches come after title matches and show a snippet around the hit.
  • ↑/↓ select, ⏎ goes to the session, Esc closes.
  • ⇥ switches between Open sessions (running or shown in a window, also ⌃⌘C) and History.

Selecting a result opens the folder in VS Code and then that conversation, or raises the window if one already shows it.

Describe it: Ask Claude

If you cannot remember any exact words, type ? and describe the session, for example ? the one where we fixed the flaky login test. You can also pick Ask Claude at the end of the history list. Hopback runs claude -p over its history index with read-only tools (Read, Grep, Glob) and shows the sessions Claude picks, each with a one-line reason. Esc or Cancel stops it.

Ask uses your own Claude Code login, so it counts towards your usage like any other prompt. Hopback finds claude on your login shell's PATH, then in /opt/homebrew/bin, /usr/local/bin and ~/.local/bin, and you can set the path in Settings, then General.

What is stored, and where

For text search Hopback builds an index of your conversation text. The first time it says "Building the history index..." and runs in the background. Afterwards it re-reads only conversations that changed. It stays on your Mac:

WhatWhere
History index (copies of conversation text)~/Library/Caches/se.zexa.hopback/
Settings~/Library/Application Support/se.zexa.hopback/
Log (never conversation text)~/Library/Logs/Hopback/

Hopback sends nothing anywhere except the update check against GitHub and Ask, which runs your own claude.

Frequently asked questions

Does Hopback search the text of conversations?

Yes. With three or more characters it also searches conversation text, after title matches, and shows a snippet around the hit.

What does Ask Claude do?

It runs your own claude command over Hopback's history index with read-only tools and returns the sessions it thinks match your description, each with a reason. It counts towards your Claude usage.

Is my conversation text uploaded?

Hopback does not upload it. The index is stored in your Mac's cache folder. Only the optional Ask feature involves Claude, through your own login.

Can I open a past session in VS Code from the search?

Yes. Pressing Return opens the folder in VS Code and then the conversation, or raises the window that already shows it.

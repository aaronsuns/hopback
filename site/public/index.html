Get back to your Claude Code sessions in VS Code.

Hopback is a macOS menu bar app for people who run several Claude Code sessions at once. It shows which session each VS Code window is on, tells you when one is waiting for you, and takes you back to any session, open or past, with a hotkey or a search.

What it does

The menu bar shows a short summary, for example ⚠1 ⚙2 · ▢8: one session needs you, two are working, and eight VS Code windows show a Claude Code session. Click a row to go there. If a window shows the session, Hopback brings that window to the front, even from another Space; otherwise it opens the folder in VS Code and then the conversation.

Know who needs you

Every session waiting for you is listed under Needs you, shown in a window or not, and a banner tells you the moment one starts waiting.

⚠️waiting for you to approve a tool call
❓waiting for an answer, or a plan review
⚙️working
💤finished its turn

Hotkeys

VS Code windows are numbered A→Z by folder. Jump straight to one, or to the next session that needs you.

⌃⌥1…⌃⌥9go to window 1–9
⌃⌥0next session that needs you
⌃⌥⇥ ⌃⌥⇧⇥next / previous window
⌃⌘Csearch open sessions
⌃⇧⌘Csearch history

All of them can be changed in Settings.

Search and Ask

Search every Claude Code conversation on your Mac by title and folder, and with three or more characters by conversation text, with a snippet around the hit.

Ask: can't remember the words? Type ? and describe it, like ? the one where we fixed the flaky login test. Hopback asks your own claude to find it, with read-only tools.

Install

Needs macOS 13 (Ventura) or newer and Visual Studio Code with the Claude Code extension.

  1. Download

    Get Hopback.dmg from the latest release and drag Hopback to Applications.

  2. Allow it to open (once)

    Hopback is not notarized by Apple yet, so macOS refuses to open it the first time. Clear the quarantine flag in Terminal:

    xattr -dr com.apple.quarantine /Applications/Hopback.app

  3. Turn on Accessibility

    Open Hopback; the welcome window ticks each step off as you go. Click Open System Settings, find Hopback in the list and switch it on. If it is already on but the step stays unticked, remove Hopback with − and add it again with +.

  4. Add the Claude Code plugin

    The plugin tells Hopback when a session is working or waiting. Click Install plugin in the welcome window, or run these in Terminal (the Claude Code panel in VS Code has no /plugin command):

    claude plugin marketplace add aaronsuns/hopback
claude plugin install hopback@hopback

    Then open a new Claude Code session (or reload the VS Code window); sessions that were already open don't load new plugins. It writes one small status file per session to ~/.claude/hopback/ and nothing else.

  5. Allow notifications

    Click Send test banner. If no banner appears, click Notification settings and allow Hopback.

Free & open source

MIT licensed. Hopback runs entirely on your Mac and sends nothing anywhere, except the update check against GitHub and Ask, which runs your own claude.

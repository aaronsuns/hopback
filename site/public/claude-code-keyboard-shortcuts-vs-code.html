Keyboard shortcuts for Claude Code in VS Code windows on Mac

When you run Claude Code in several VS Code windows, the mouse is the slow part. These are the global shortcuts Hopback adds, and how to change them.

Download Hopback for macOS - free, MIT

macOS 13 or newer, Visual Studio Code with the Claude Code extension. Source on GitHub.

The default shortcuts

DefaultDoes
⌃⌥1 … ⌃⌥9go to VS Code window 1–9, as numbered in the menu
⌃⌥0go to the next session that needs you; press again for the one after
⌃⌥⇥ / ⌃⌥⇧⇥next / previous VS Code window
⌃⌘Csearch open sessions
⌃⇧⌘Csearch history

Stable window numbers

Windows are numbered A→Z by folder in the menu, so a project keeps the same number while its window stays open. That lets you build muscle memory: ⌃⌥2 is always the same project.

Change them

Open Settings, then Shortcuts: click a shortcut and press the new keys, or Clear it. Hopback refuses combinations without ⌃, ⌥ or ⌘, duplicates, and ones macOS keeps for itself.

Search instead of numbering

⌃⌘C opens a search over the sessions that are open or running: type part of a title or folder, press ⏎ and you are there. For older conversations use history search.

See also Claude Code in multiple VS Code windows.

Frequently asked questions

Are the shortcuts global?

Yes. They work from any app, because Hopback registers them with macOS.

Why do I need Accessibility permission?

Hopback needs it to list VS Code's windows and raise the one you pick.

Can I use more than nine windows?

The number keys cover windows 1 to 9. For the rest use the next/previous window shortcut or the search.

Can I clear a shortcut I do not use?

Yes, with Clear in Settings, then Shortcuts.

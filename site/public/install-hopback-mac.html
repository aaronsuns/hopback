Install Hopback on Mac: Homebrew or dmg, and the first-run steps

Hopback is free and open source. This page covers both install routes, why macOS warns the first time, and what to click in the welcome window.

Download Hopback for macOS - free, MIT

macOS 13 or newer, Visual Studio Code with the Claude Code extension. Source on GitHub.

Option 1: Homebrew

brew install --cask aaronsuns/tap/hopback

The cask also clears the quarantine flag for you, so Hopback opens right away.

Option 2: the dmg

  1. Download Hopback.dmg from the latest release and drag Hopback to Applications. It needs macOS 13 (Ventura) or newer, Apple silicon or Intel.
  2. Hopback is not notarized by Apple yet (that needs a paid Apple developer account), so macOS refuses to open it the first time. Clear the quarantine flag once in Terminal: xattr -dr com.apple.quarantine /Applications/Hopback.app
  3. Open Hopback.

The welcome window

It ticks each step off by itself:

  • Accessibility: lets Hopback list VS Code's windows and raise one. Click Open System Settings, find Hopback and switch it on.
  • Claude Code plugin: click Install plugin. By hand it is claude plugin marketplace add aaronsuns/hopback and claude plugin install hopback@hopback. Open a new session afterwards: sessions already open do not load new plugins.
  • Notifications: click Send test banner and allow Hopback if macOS asks.
  • Start at login: on by default.

Requirements

Visual Studio Code with the Claude Code extension. Cursor and VS Code Insiders are not supported yet.

If sessions never show a waiting glyph

Install the plugin, then restart your sessions. Diagnostics in the menu shows whether the plugin is installed and has run.

Frequently asked questions

Is Hopback safe to open if it is not notarized?

The source is on GitHub under the MIT licence and releases are built by GitHub Actions. macOS warns because the app has not been through Apple's notarization, which needs a paid developer account.

How do I uninstall Hopback?

Quit it from its menu, move it to the Trash, and in Claude Code run /plugin uninstall hopback@hopback and /plugin marketplace remove hopback.

Does it update itself?

Yes. It checks for updates at start and every 6 hours, and installs them in the background by default.

Which macOS versions work?

macOS 13 (Ventura) or newer, on Apple silicon or Intel.

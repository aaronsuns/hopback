Hopback / Claude Code session switcher for VS Code

A Claude Code session switcher for VS Code on Mac

Run Claude Code in five VS Code windows and you will soon lose track of which one is doing what. Hopback is a macOS menu bar app that lists every window and its session, and takes you to the right one with a hotkey.

Download Hopback for macOS - free, MIT

macOS 13 or newer, Visual Studio Code with the Claude Code extension. Source on GitHub.

The problem with several Claude Code sessions

Claude Code works best when you let it run while you do something else, so it is natural to have a session in each of several projects. The cost is switching: cmd-tab shows a row of identical VS Code icons, and each window might be waiting for you to approve a tool call, asking a question, or happily working. Hopback exists to answer "which window, and does it need me?" without hunting.

What Hopback shows in the menu bar

The menu bar shows a short summary such as ⚠1 ⚙2 · ▢8: one session needs you, two are working, and eight VS Code windows show a Claude Code session. The glyphs mean:

GlyphMeaning
⚠️waiting for you to approve a tool call
❓waiting for an answer to a question, or for a plan to be reviewed
⚙️working
💤finished its turn, nothing pending

The menu has three parts: Needs you (every session waiting for you, whether a window shows it or not), Windows (every VS Code window, numbered A to Z by folder, with the session it shows) and Working in background (busy sessions that no window shows).

Jump to the right window with a hotkey

DefaultDoes
⌃⌥1 to ⌃⌥9go to VS Code window 1 to 9, as numbered in the menu
⌃⌥0go to the next session that needs you; press again for the one after
⌃⌥⇥ / ⌃⌥⇧⇥next / previous VS Code window
⌃⌘Csearch open sessions
⌃⇧⌘Csearch history

Because windows are numbered alphabetically by folder, the number of a project stays predictable. If a window shows the session you asked for, Hopback brings that window to the front, even from another Space. If not, it opens the folder in VS Code and then the conversation. Every shortcut can be changed or cleared in Settings, then Shortcuts.

Find a session by name instead

Press ⌃⌘C to search the sessions that are open or running, or ⌃⇧⌘C to search every Claude Code conversation on the Mac. See how to search Claude Code history.

Requirements and limits

  • macOS 13 (Ventura) or newer, Apple silicon or Intel.
  • Visual Studio Code with the Claude Code extension. Cursor and VS Code Insiders are not supported yet.
  • Accessibility permission, so Hopback can list VS Code's windows and raise one.
  • The Hopback Claude Code plugin, which tells Hopback when a session is working or waiting (see how it uses Claude Code hooks). Without it you still get windows and search, but not the status glyphs.

VS Code saves which conversation a window shows only every so often, so Hopback can lag a few seconds; until then it guesses the most recently active session in that folder.

Install from the latest release; Hopback is not notarized yet, so clear the quarantine flag once with xattr -dr com.apple.quarantine /Applications/Hopback.app. Related: working with Claude Code in multiple VS Code windows.

Frequently asked questions

Does Hopback work with Cursor?

Not yet. Hopback supports Visual Studio Code with the Claude Code extension. Cursor and VS Code Insiders are not supported yet.

Does it work with Claude Code in a terminal?

Partly. Terminal sessions show up under Needs you, Working in background and in search, but only VS Code windows are listed and raised.

Does Hopback send my conversations anywhere?

No. It runs on your Mac and sends nothing, except the update check against GitHub and the optional Ask feature, which runs your own claude command.

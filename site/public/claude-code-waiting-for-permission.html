Claude Code is waiting for permission: how to notice it

You start a task, switch to another window, and come back to find Claude Code has been waiting for your approval for twenty minutes. Here is how to stop that from happening.

Download Hopback for macOS - free, MIT

macOS 13 or newer, Visual Studio Code with the Claude Code extension. Source on GitHub.

Why a session waits without you noticing

Claude Code pauses when it wants to run a tool that needs your permission, when it asks you a question, or when it has a plan for you to review. If the VS Code window is behind another one, or on another Space, nothing tells you. The session simply sits there and the work stops.

What Hopback shows

Hopback adds a short summary to the Mac menu bar, for example ⚠1 ⚙2 · ▢8: one session needs you, two are working, and eight VS Code windows show a Claude Code session.

GlyphMeaning
⚠️waiting for you to approve a tool call
❓waiting for an answer to a question, or for a plan to be reviewed
⚙️working
💤finished its turn, nothing pending

The Needs you section of the menu lists every waiting session, whether a window shows it or not.

Get a banner and jump straight to it

When a session starts waiting, Hopback shows a macOS banner. Click it to go to that session: if a window shows it, Hopback raises that window, even from another Space; otherwise it opens the folder in VS Code and then the conversation. Press ⌃⌥0 to go to the next session that needs you, and again for the one after. Banners for approvals and for questions can be switched off separately in Settings.

How Hopback knows

A small Claude Code plugin reports the hook events (a session working, waiting, finished). It writes one small status file per session to ~/.claude/hopback/ and nothing else. See Claude Code hooks for session status for the details.

New to Hopback? Install it with Homebrew or the dmg.

Frequently asked questions

Does Claude Code notify me when it needs permission?

Claude Code shows the prompt in its own panel. If that window is hidden you have to look for it yourself. Hopback adds a menu bar glyph, a macOS banner and a hotkey that takes you to the waiting session.

Which sessions count as needing me?

Sessions waiting to approve a tool call, to get an answer to a question, or to have a plan reviewed.

Can I turn the banners off?

Yes. Banners for approvals and for questions are separate switches in Settings.

Does it work with Cursor?

Not yet. Hopback supports Visual Studio Code with the Claude Code extension.
